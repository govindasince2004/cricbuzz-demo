# Cricbuzz Demo

A front-end clone of the Cricbuzz homepage — React + Vite + Tailwind CSS v4.

## Start here

The app lives in `frontend/`. Go there first:

```bash
cd frontend
npm install     # first time only
npm run dev     # start the dev server
```

Then open http://localhost:5173

## Commands (run inside `frontend/`)

| Command | What it does |
| --- | --- |
| `npm install` | Install dependencies |
| `npm run dev` | Start the dev server with hot reload |
| `npm run build` | Build for production (outputs to `dist/`) |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run oxlint |

## Notes

- `main.py` in the repo root is a standalone Python scraper, not part of the app. You can ignore it.
